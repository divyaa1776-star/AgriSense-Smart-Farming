Data limitations

The NASA POWER file covers one date and contains missing-value markers. It is not used for training.

Upload your own training CSV

Upload a labelled dataset to validate, retrain and recalculate model metrics. This does not make the data scientifically validated automatically.

Required columns: soil_moisture, temperature, humidity, rainfall_mm, light_intensity, water_level, wind_speed, crop_type, irrigation_needed. Target labels must be 0 or 1; minimum 50 rows with both classes.

Current dataset status will appear here.

Project scope

  • Data processing and exploratory analysis
  • Classification model training and comparison
  • Clustering and PCA-based visualization
  • AI Experiment Studio includes regression, ANN, Apriori-style frequent itemsets, clustering, A* grid search, BFS/DFS/UCS, TSP heuristics, irrigation schedule optimization, CSP, Water Jug BFS, Minimax, dataset profiling and experiment logging.
  • No live weather API, physical sensor or pump is connected.
